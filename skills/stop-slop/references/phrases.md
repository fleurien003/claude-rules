# 지울 말, 바꿀 말

## 예고·인사 (본론 전 헛기침)

지우고 본론부터 쓴다.

- "오늘은 ~에 대해 알아보겠습니다 / 소개해드릴게요"
- "안녕하세요, 여러분!" (블로그 첫인사는 한 줄이면 충분하다)
- "~에 대해 이야기해보려고 합니다"
- "먼저 ~부터 살펴보겠습니다"
- "그럼 지금부터 시작해볼까요?"
- "많은 분들이 궁금해하시는"
- "요즘 핫한 / 요즘 난리난"

## 맺음말 상투어

- "도움이 되셨길 바랍니다"
- "여러분도 꼭 한번 ~해보세요!"
- "지금까지 ~였습니다"
- "궁금한 점은 댓글로 남겨주세요" (정말 받을 거면 남긴다)
- "결론적으로 / 요약하자면 / 정리하자면" (짧은 글에서 요약은 반복이다)

## AI가 좋아하는 단어

| 피할 말 | 대신 |
|---|---|
| 다양한 | 무엇이 몇 개인지 쓴다 ("메뉴 12가지") |
| 효과적으로, 효율적으로 | 무엇이 얼마나 나아졌는지 쓴다 |
| 중요한 역할을 한다 | 무슨 일을 하는지 쓴다 |
| 핵심은 ~이다, 관건은 | 바로 그 내용을 쓴다 |
| 인사이트, 시너지, 솔루션 | 알게 된 것, 함께 낸 효과, 해결책 |
| 여정, 한 걸음 더 나아가 | 빼거나 실제 과정을 쓴다 |
| 완벽한, 최고의, 강력 추천 | 무엇이 좋았는지 쓴다 |
| 특별한 경험, 잊지 못할 | 어떤 장면이었는지 쓴다 |
| 만족스러웠다 | 무엇이 어땠는지 쓴다 |
| 퀄리티가 좋다 | 맛, 식감, 마감처럼 무엇이 좋은지 쓴다 |

## 강조 부사

한 문단에 하나 넘게 나오면 줄인다. 대부분 지워도 뜻이 같다.

- 정말, 진짜, 너무, 매우, 굉장히, 엄청, 완전
- 사실, 실제로, 솔직히 (진짜 고백이 아닐 때)
- 확실히, 분명히, 당연히
- 특히 (문단마다 나오면)

## 흐릿한 끝맺음

단정할 수 있으면 단정한다.

| 피할 말 | 대신 |
|---|---|
| ~라고 할 수 있습니다 | ~입니다 |
| ~할 수 있을 것 같습니다 | ~합니다 / ~할 겁니다 (근거가 있으면) |
| ~하는 것이 중요합니다 | ~하세요 / ~해야 합니다 |
| ~하는 것이 필요합니다 | ~해야 합니다 |
| ~하는 경향이 있습니다 | 얼마나 자주인지 쓴다 |
| ~로 보입니다 (확인한 사실인데) | ~입니다 |

## 번역투

영어 문장 구조를 옮긴 표현이다. 조사나 동사 하나로 줄인다.

| 번역투 | 한국어 |
|---|---|
| ~에 대해 이야기하다 | ~을 이야기하다 |
| ~를 통해 배웠다 | ~에서 배웠다 / ~하면서 배웠다 |
| ~에 있어서 중요하다 | ~에 중요하다 / ~할 때 중요하다 |
| ~함에 있어 | ~할 때 |
| ~를 가지고 있다 (특징을) | ~가 있다 / ~하다 |
| 회의를 가졌다 | 회의했다 |
| ~에 의해 만들어졌다 | ~가 만들었다 |
| ~되어지다, ~되어진 | ~되다, ~된 |
| ~로 인해 | ~ 때문에 / ~해서 |
| ~에 위치한 | ~에 있는 |
| ~의 경우 | ~는 |
| ~와 함께 (with 직역) | ~와 / ~하고 |
| 가장 ~한 것 중 하나 | 무척 ~한 / 순위를 쓴다 |
| 그것은 ~이다 (it 직역) | 주어를 빼거나 이름을 쓴다 |
| ~하는 데 있어 도움이 된다 | ~하는 데 도움이 된다 / ~하기 좋다 |

## 명사 뭉치

동사로 풀면 읽기 쉬워진다.

- "개선을 진행했습니다" → "고쳤습니다"
- "확인 작업을 수행했습니다" → "확인했습니다"
- "사용자 경험 향상을 위한 방안 마련" → "사용자가 덜 헤매게 하는 방법"
- "~에 대한 검토가 필요합니다" → "~을 검토해야 합니다"

## 속을 비운 선언

중요하다고 말만 하고 무엇이 중요한지는 안 말하는 문장. 지우거나 그 내용을 쓴다.

- "시사하는 바가 크다"
- "생각해볼 필요가 있다"
- "주목할 만하다"
- "의미 있는 변화다"
- "다시 한번 깨닫게 된다"
