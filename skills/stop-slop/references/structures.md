# 피할 문장 구조

## 대비 공식

| 패턴 | 문제 |
|---|---|
| "단순히 A가 아니라 B다" | 뻔한 반전 |
| "A가 문제가 아니다. B가 문제다." | 공식 같은 뒤집기 |
| "중요한 건 A가 아니라 B다" | 예측 가능한 전환 |
| "A처럼 보이지만 사실은 B다" | 준비된 반전 |
| "A를 넘어 B로" | 슬로건 투 |

**대신:** B만 쓴다. "문제는 B다."

## 부정 나열

"A도 아니고, B도 아니다. 바로 C다." 무엇이 아닌지 늘어놓다가 마지막에 공개한다.

**대신:** C부터 쓴다.

## 질문 던지고 바로 답하기

| 패턴 | 문제 |
|---|---|
| "왜 그럴까요? 바로 ~때문입니다." | 가짜 궁금증 |
| "그렇다면 어떻게 해야 할까요?" | 소제목을 문장으로 쓴 것 |
| "~라면 어떨까요?" | 소크라테스 흉내 |

**대신:** 답을 바로 쓴다.

## 셋씩 나열

"맛, 분위기, 서비스 모두 완벽했다." AI는 셋을 좋아한다. 글 전체에 셋씩 묶음이 여러 번 나오면 티가 난다.

**대신:** 정말 좋았던 하나를 자세히 쓰거나, 둘로 줄인다.

## 끊어 치기

| 패턴 | 문제 |
|---|---|
| "맛. 가격. 분위기. 모든 게 완벽했다." | 억지 강조 |
| "그게 전부다. 그게 답이다." | 연출된 단순함 |
| "그리고, 깨달았다." | 가짜 깨달음 |

**대신:** 온전한 문장으로 쓴다.

## 문단마다 명언으로 끝내기

"결국 중요한 건 마음이다." 같은 한 줄로 문단을 매번 닫는다.

**대신:** 몇 문단은 그냥 내용으로 끝낸다. 명언처럼 들리는 문장은 고쳐 쓴다.

## 사물이 사람처럼 행동하기

| 패턴 | 고치기 |
|---|---|
| "데이터가 말해준다" | 누가 데이터를 보고 무엇을 알았는지 |
| "변화가 시작됐다" | 누가 무엇을 바꿨는지 |
| "공간이 편안함을 선사한다" | 의자가 어떻고 조명이 어떤지 |
| "한 그릇에 정성이 담겼다" | 무엇을 보고 정성을 느꼈는지 |

**대신:** 행동한 사람이나 구체적인 대상을 쓴다.

## 멀리서 내려다보는 말투

| 패턴 | 문제 |
|---|---|
| "현대인들은 ~한다" | 강의투 |
| "많은 사람들이 ~한다" | 근거 없는 일반화 |
| "우리 모두 ~한 경험이 있을 것이다" | 억지 공감 |

**대신:** 독자를 장면 안에 넣는다. "퇴근하고 9시에 가면 웨이팅이 없다."

## 같은 어미 반복

"~했습니다. ~였습니다. ~좋았습니다. ~추천합니다." 같은 어미가 줄줄이 이어진다.

**대신:** 어미를 섞는다. 문장을 합치거나 나눈다. 구어체 글이면 "~더라고요", "~거든요"를 섞되 이것도 반복하지 않는다.

## 형식 과잉

| 패턴 | 고치기 |
|---|---|
| 짧은 글에 소제목이 잔뜩 | 소제목을 빼고 문단으로 |
| 문장마다 굵은 글씨 | 한 글에 한두 곳만 |
| 이모지 줄줄이 (✨💯🔥) | 빼거나 하나만 |
| "~: " 콜론으로 시작하는 문장 | 문장으로 풀기 |
| 줄표(—) | 쉼표나 마침표 |

## 과한 균형

"장점도 있지만 단점도 있다", "사람마다 다를 수 있다"로 모든 판단을 흐린다.

**대신:** 글쓴이의 판단을 쓴다. 정말 사람마다 다르면 누구에게 맞고 누구에게 안 맞는지 쓴다.
